# GrowthRadar — agent orientation

## What this project is

A public **ProductHunt-style leaderboard** (`GrowthRadar`) of newly launched,
worth-studying SaaS/AI products. It is a Next.js 16 static site that renders
data produced by the sibling `monitors/` + `analyzers/` pipeline.

This directory was previously a different product (a C-side SEO landing-page
generator, "growthlanding.ai"). That product has been **fully removed**; only
the build config, design tokens, and root layout were kept.

## Architecture

- **Static data**: `public/data/` holds JSON generated by
  `analyzers/scripts/export-webui.py` (run on bishenai2, committed to repo).
  - `featured.json` — LLM-enriched top domains (rich cards)
  - `all.json` — all scored domains (slim cards, ~tens of thousands)
  - `stats.json` — aggregate headline numbers
  - `detail/<a-z|0|_>.json` — full detail per domain, sharded by first char
- **No runtime DB / API**. The frontend fetches static JSON only.
- **Three-state semantics**: every boolean signal is `true | false | null`.
  `null` = "not measured" and must render as "unknown", NOT as "no".
- **Category dual-source**: prefer LLM `details.llm_enrich.category` (already
  resolved into the top-level `category` field by the export script); it falls
  back to Stage 0 `category_guess`.

## Commands

```bash
npm run dev      # dev server on :3000
npm run build    # production build
npm run lint
```

## Key files

```
src/
  app/layout.tsx               # root layout + metadata
  app/globals.css              # Tailwind v4 @theme tokens (dark indigo)
  app/page.tsx                 # home = leaderboard (featured + all tabs)
  app/domain/[domain]/page.tsx # detail page
  components/                  # Header, StatsBar, TabSwitch, SignalBadges,
                               #   LeaderboardCard, ScoreBar
  lib/data.ts                  # static-JSON fetch helpers
  lib/format.ts                # three-state bool / date / score formatting
  types/index.ts               # data contracts (mirror export-webui.py)
```

## Design tokens (globals.css `@theme inline`)

Dark indigo theme. Primary `#4F46E5`, accent `#6366F1`, accent2 (PH orange)
`#F97316`, card `#111827`, background `#0B0F14`. Utility classes `bg-card`,
`text-text-secondary`, `border-border`, `bg-primary`, `text-accent2` are valid.

## Next.js 16 caveat

See `AGENTS.md`: Next.js 16 has breaking changes vs older majors. Consult
`node_modules/next/dist/docs/` before using App Router / dynamic route /
metadata APIs.
